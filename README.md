# CLI-Tool-ftc
This simple CLI tool gives users the opportunity to quickly copy file contents

## 🚀 Getting Started

Follow these simple steps to connect this tool and start using it directly in your Terminal.

### 🍏 MacOS
Open this repository https://github.com/mikhayloboikodev/homebrew-cli-tools and follow the instructions in the README.md file there.

### 🐧 Linux 
```bash
git clone https://github.com/mikhayloboikodev/CLI-Tool-ftc.git
```
```bash
cd CLI-Tool-ftc
```
```bash
sudo mv ftc /usr/local/bin/
```
---
* **Quick Usage:**
  ```bash
  ftc < input.txt
  ```
